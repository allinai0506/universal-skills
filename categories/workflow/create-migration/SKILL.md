# create-migration

创建 Flyway 数据库迁移脚本，遵循项目迁移规范。

## 执行步骤

### 1. 确定下一版本号

```bash
# 查看当前最大版本号
ls backend/src/main/resources/db/migration-mysql/ | sort -V | tail -1
```

下一版本号 = 当前最大版本号 + 1 （例如 V128 → V129）

### 2. 创建迁移脚本

- **路径**: `backend/src/main/resources/db/migration-mysql/V{version}__{description}.sql`
- **命名**: `V{数字}__{英文短横线描述}.sql`，例如 `V129__add_tender_budget_field.sql`
- **规范**: MySQL 8.0 兼容，**不得**使用 H2 特有语法（`GENERATED BY DEFAULT AS IDENTITY`、`NEXT VALUE FOR` 等）

### 3. 创建回滚脚本

- **路径**: `backend/src/main/resources/db/rollback/migration-mysql/U{version}__{description}.sql`
- 与迁移脚本的版本号和描述一致，前缀用 `U` 替代 `V`
- 回滚脚本应逆序撤销迁移的变更（DROP 列/表放在最后）

### 4. 验证

```bash
bash .claude/skills/create-migration/scripts/validate-migration.sh \
  backend/src/main/resources/db/migration-mysql/V{version}__{description}.sql \
  backend/src/main/resources/db/rollback/migration-mysql/U{version}__{description}.sql
```

### 5. 提交前确认

- [ ] 版本号递增（比当前最大版本号 +1）
- [ ] 文件命名符合 `V{数字}__{描述}.sql` 模式
- [ ] 回滚脚本存在且版本号匹配
- [ ] SQL 语法兼容 MySQL 8.0
- [ ] 已通过验证脚本检查
